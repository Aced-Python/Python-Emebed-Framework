# Roadmap

## P0

Core embeds, validation, colors, markdown helpers, local attachments, Buttons, Components V2 message layouts, serialization/debugging, examples, CI, migration docs.

## P1

String-select callbacks, reusable component factories, persistent-view helpers, modal builders, localization hooks, snapshot testing helpers.

## P2

Pagination, confirmation dialogs, component state, permission-aware UI, `frame check`, visual-preview protocol, design tokens.

## P3

Features that belong outside the core unless there is strong evidence they add value: rate-limit abstractions, background tasks, a replacement command framework, CSS-like layout semantics.
