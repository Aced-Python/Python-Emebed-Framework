# Research sources

Frame's initial architecture was checked against the current official references available during the project build:

- Discord Component Reference: https://docs.discord.com/developers/components/reference
- Discord Message Resource: https://docs.discord.com/developers/resources/message
- discord.py interactions API: https://discordpy.readthedocs.io/en/stable/interactions/api.html
- discord.py API reference: https://discordpy.readthedocs.io/en/stable/api.html
- discord.py PyPI releases: https://pypi.org/project/discord.py/

The current verified PyPI release checked for this repository was `2.7.1`, released March 3, 2026. Components V2 support is available in `discord.py` 2.6+.
